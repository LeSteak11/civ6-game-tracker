## 7. CONTENT SYSTEM — the Figma component architecture

The goal: **one file, one component set, so that producing a post is a data-entry task and not a design task.** You have the Figma skill to build this in a day. Building it is the actual fix for the cadence problem — motivation is not a system, and you already have two years of evidence for that.

### Master frame

`1080 × 1350`, with a **1080×1080 safe zone** guide-locked at the top. Nothing essential outside it.

### Slot structure (every archetype, identical)

```
┌─ CAQ-POST/[archetype] ──────────────┐
│  bg              (variant-driven)   │
│  texture         (boolean)          │
│  glow            (color = team-1)   │
│  subject         (image slot)       │
│  contact-shadow  (boolean)          │
│  display-type    (variant text)     │
│  name-lockup     (first + surname)  │
│  meta-block      (school/sport/yr)  │
│  ── PERSISTENT ──                   │
│  credit-bar      (📸 photographer)  │
│  caq-mark        (corner, locked)   │
└─────────────────────────────────────┘
```

`credit-bar` and `caq-mark` are **locked, non-deletable layers in the base component.** Every instance inherits them. You cannot ship an uncredited post because the component won't let you. That is the point — make the trust signal structural instead of a habit you have to remember.

### Variants — 7 archetypes off one component set

| Archetype | Display text | Feeds |
|---|---|---|
| `COMMITTED` | COMMITTED | Signing/NLI season |
| `SPOTLIGHT` | SPOTLIGHT | Evergreen — your fill content |
| `MILESTONE` | PR / RECORD / ALL-AMERICAN | Result-driven, SID-relevant |
| `GAMEDAY` | vs. [OPP] + date | Proves you can serve a comms calendar |
| `SENIOR` | SENIOR DAY | Seasonal, high emotional pull |
| `PROCESS` | BEFORE / AFTER split | Trust content |
| `CREDIT` | SHOT BY [name] | Photographer spotlight |

### Variables — this is where the leverage is

**Color mode per school.** Figma variable modes let you define `team-1`, `team-2`, `team-accent`, `type-on-team` once per school, then switch the entire composition to Kentucky, Oregon, or Baylor with a dropdown. Build 25–30 school modes once. School switching becomes zero design work forever.

**Type styles, fixed:**

- `display` — condensed caps, one face, one weight. Never changes.
- `name-primary` — script or high-contrast serif, surname.
- `name-secondary` — the first name, smaller, sits above.
- `meta` — sans, **minimum 28px at 1080 width.** Your current metadata is illegible; this rule fixes it permanently.
- `credit` — sans, minimum 24px, 80% opacity, fixed position.

**Boolean toggles:** texture on/off, glow on/off, contact shadow on/off, second subject on/off.

### Production run

1. Cut out subject → drop into `subject` slot
2. Set school mode from dropdown
3. Set archetype variant
4. Type name, meta, photographer
5. Export

**Target: under 4 minutes per piece once the system exists.** Sixteen posts becomes a single afternoon. That is what makes 4/week survivable on a week when you don't feel like it — which is every week eventually, and that is exactly the week the system has to hold.

[Athlete first + last] · [School] [Sport]
[One editorial line — the commitment, the result, the milestone]

Photo used with permission. Design by [your handle].
